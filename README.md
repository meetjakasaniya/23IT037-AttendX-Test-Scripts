
# AttendX Test Scripts

## Project Overview
AttendX is a student attendance application.
This repository demonstrates version control of test scripts
using Git, GitHub, and Visual Studio Code.

## Test Scripts

### 1. login_test.py
Tests valid login, invalid password, and empty username scenarios.

### 2. attendance_marking_test.py
Tests Present and Absent attendance, empty student ID,
and invalid attendance status.

## Requirements
- Python 3
- Git
- Visual Studio Code

## How to Run
Open a terminal in this folder and execute:

```bash
python login_test.py
python attendance_marking_test.py
```

On Windows, if `python` is not recognized, try `py` instead.

## Version Control
Git is used to track file changes and commits.
GitHub is used to store and share the repository remotely.

## Note
These scripts simulate application logic for educational purposes.
They do not connect to a live AttendX application.
